The Variant Lab.

Pick any set of allowed takes, move the book, or turn the game inside out (whoever takes the book loses). The lab solves it exactly by backward induction and tells you who should start, what to take, and whether a pattern emerges.

What the lab teaches

🔁

Periodic, eventually

Each position depends only on the last max(S) positions, so the win/lose pattern must repeat. Try {1,3,4}: period 7, but with two traps per period. Try {1,2,5}: the extra “5” is useless and the period collapses to 3.

📍

The book can move

A book at position p means only the top n − p + 1 prizes matter: it is the same game with a smaller n. The first-player trap shifts accordingly.

🙃

Misère flips the script

When the last take loses, the trap positions shift by one (for the plain 1–6 game: positions ≡ 1 mod 7). Amanda still wins any n, since she picks the starter.
